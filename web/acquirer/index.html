Sapphire is a production-graded autonomy control plane.

Sapphire turns one operator, owned local compute, and strict safety gates into an auditable intelligence, trading, and operations system. Every decision flows through a versioned risk kernel; every emitted artifact carries a provenance envelope; every external surface is dry-run by default and live only behind explicit env-flag gates. The pages an acquirer can walk in tomorrow morning and read - Diligence Packet, Capabilities, Safety Posture - paint a complete picture of what they would be acquiring without having to ask the operator a single question.

Safety Posture

Kill switch

Global + security kill switches at lib/core/kill_switch.py. Witnessed invariants: drawdown threshold, consecutive-loss threshold, latency threshold, position-size cap, idempotency. Every fire is an event-bus event; every reset is logged.

Confirmation firewall

2-phase commit on destructive actions at lib/core/confirmation_firewall.py. Confirmation tokens expire; archive flow records the operator decision. The trading critical path is gated by CODEOWNERS.

Provenance envelopes

Every generated artifact carries {generator, model, prompt_hash, source_hashes, ttl, version}. Verification is a one-liner via scripts/ops/provenance_verify.py.

No-spend posture

[skip ci] on every commit; hosted GitHub Actions billing is gated by vars.SAPPHIRE_RUNNER. Local CI verification is the merge gate.

Live capital posture

Crypto-only, manual confirmation, $5 first-order cap, $50 pilot. Stock automation is not yet authorized. The full ramp from paper to live is documented in live-trading-ramp-memo.md.

Secret handling

Secrets live at ~/.sapphire/secrets.env (mode 0600). LaunchAgent plists do not embed credentials. Live external paths load secrets only when their env flag is set and then only into the calling process.
