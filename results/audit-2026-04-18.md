## 5. New Module Integration: regime.py, cpcv.py, vpin.py

### Status Before Audit

All three modules existed only in worktree branch `pensive-beaver-611dc8`, not in the main tree.

### Actions Taken

1. **Copied 3 source modules** to `lib/analytics/`: `regime.py` (GMM regime detection), `cpcv.py` (Combinatorial Purged Cross-Validation), `vpin.py` (Volume-Synchronized Probability of Informed Trading)
2. **Updated `lib/analytics/__init__.py`** — Added try/except export blocks for all three modules
3. **Wired into signal_enhancer.py** — Added GMM regime + VPIN imports with try/except guards, added `gmm_regime`, `gmm_regime_prob`, and `vpin` fields to `EnhancedSignal` dataclass, added regime crisis/mean-reverting confidence adjustments and VPIN flow toxicity adjustments to `enhance()` method
4. **Copied 37 tests** to `tests/unit/`: `test_regime.py` (10 tests), `test_cpcv.py` (14 tests), `test_vpin.py` (13 tests)

### What Each Module Does

- **regime.py**: Fits 2/3-state Gaussian Mixture Model on rolling features (log returns, realized vol, volume z-score, skewness) to classify market as `trend`, `mean_reverting`, or `crisis`. 5-minute per-symbol TTL cache.
- **cpcv.py**: Lopez de Prado-style combinatorial purged cross-validation. Generates all C(N,k) splits with purging + embargo to prevent lookahead bias in backtests.
- **vpin.py**: Lee-Ready bulk volume classification → rolling flow imbalance. VPIN > 0.7 = toxic flow. Reduces signal confidence during informed-trading spikes.
