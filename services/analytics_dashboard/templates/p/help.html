DATA_PROVENANCE

Trading signals. TradingView (Mac orchestrator) → webhook (Windows :9090) → signal logger (Mac :18081) → BigQuery trading_signals. Live BTC fills via Robinhood Crypto API (Ed25519-signed REST).

Threat intel. cyber-threat-bot (Cloud Run, us-central1) pulls CISA Known Exploited Vulnerabilities, NVD, MITRE ATT&CK, scores with EPSS + composite actionability. We proxy /api/threats/live same-origin to dodge CORS.

Regime. Daily collector emits regime label (RISK_ON / RISK_OFF / TRANSITION), score, BTC dominance, fear/greed, average funding. We surface valid (non-UNKNOWN) rows + a staleness watermark.

Markets. CoinGecko free tier with 60s in-process cache (Cloud Run instances are ephemeral so per-instance cache is sufficient). Top 10 by market cap with 7-day sparkline.

Service health. Telemetry collector LaunchAgent on the Mac writes heartbeat rows to BQ service_health every 60s. The dashboard rolls up the last 60min and reports p50/p95 response times.

USING_THE_BRAIN

  1. Visit /p/brain — health score, regime, signals/24h, CVEs/24h are at the top.
  2. Narrative is a plain-English sentence per silo. If a silo is degraded, it's omitted from the narrative and added to priority actions.
  3. Priority actions are concrete: "trading: 0 signals in last 24h — check signal-logger LaunchAgent on Mac".
  4. Correlations match against a deterministic catalog: telemetry_collapse, service_inference_failover, threat_with_silent_trading, tho_health_degraded.
  5. To seed the rolling sparkline: curl /api/brain/synthesis?persist=1 writes a row to brain_synthesis.

INTERPRETING

Regime. RISK_ON boosts long signals (×1.05), RISK_OFF penalizes them (×0.80) — see SignalEnhancer. TRANSITION is neutral. Score is in [-1, +1]; magnitude is conviction. Fear/greed is the Crypto Fear & Greed Index 0..100.

Threats. Severity ranks by CVSS bucket (CRITICAL ≥ 9.0, HIGH 7.0–8.9, etc.). KEV-tagged means it's been observed exploited in the wild — patch first. EPSS is the exploit-probability score in [0, 1] from the FIRST.org model.

Markets. Sparkline color: green = +24h, red = -24h. Mcap shows USD; BTC dominance is BTC mcap / total crypto mcap.
