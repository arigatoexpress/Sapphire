What is Sapphire OS

$ cat MANIFESTO.md

THE_THESIS

Trading desks watch one screen. Threat-intel desks watch another. Compliance, regional intel, on-chain analytics, customer ops — each in its own silo, each producing data the others would die for. Sapphire OS is the integration layer: a single decision surface that observes every silo, correlates across them, and emits actions you can read in plain English.

Telegram-first. Agent-driven. Event-bus mediated. Built on top of claw-code (Rust agent runtime) with a Python plugin layer. Pure deterministic synthesis at the core — no LLM hop in the critical path. Fast, predictable, auditable.

THE_BRAIN

Three deterministic endpoints behind /api/brain/*: synthesis observes every silo and emits a single situational-awareness brief (degraded silos, top priority actions, health score 0..1); correlate runs a pattern catalog over the latest silo state for ranked cross-silo correlations; history backs the rolling sparkline so you can see the system's mood drift over 48 hours.

No LLM hop in v0. Predictable. Auditable. The /p/brain page is the live view.
