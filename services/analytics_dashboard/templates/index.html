Sapphire OS — Quick Guide

Unified production dashboard at sapphirealpha.xyz

Silo cards

The six cards at the top are the high-level entry points. Each shows a status pill (live, ok, degraded, down, phase-0, active). Click a card to dive into that silo:

  • THO Operations — Texas Home Outlet production at tho.sapphirealpha.xyz
  • Threat Intel — opens the live JSON feed from cyber-threat-bot Cloud Run
  • Wildfire Watch — passkey-gated admin frontend (in build)
  • Intelligence — scrolls to the regime + predictions panels below
  • Regional Intel — passkey-gated admin frontend (in build)
  • Hackathon Lanes — opens the Sapphire monorepo

Production telemetry

Six KPIs with 24h sparkline trends. Each value is real BigQuery data — no paper-trading numbers. Sub-text shows context (error rate, healthy/total, etc.).

Charts

Two stacked charts: inference calls per hour over 24h (split by tier), and threat severity per day over 30d. Hover a chart for tooltips.

Service health

Each service's p50 + p95 response time over the last 60 minutes, with status pill (healthy / degraded / down). The latency bar visualizes the p50.

Banners

Yellow banner appears when a data collector is stale. The regime collector specifically broke around 2026-04-18 — that's why the regime panel shows an "ago" warning.

Keyboard shortcuts

? open help · Esc close modal

Refresh

Every panel auto-refreshes every 60 seconds. The footer shows the last refresh timestamp.

Data sources

Footer links expose every backing endpoint. All BigQuery-backed endpoints fail-safe to empty payloads if a table is missing — the dashboard never 500s.
