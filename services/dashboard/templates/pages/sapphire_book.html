01 System Overview ›

Sapphire is an autonomous trading + operations + intelligence platform designed for 24/7 market participation with minimal human intervention. It runs across a 4-device mesh: Mac commander, Windows GPU workstation, and two Raspberry Pi nodes.

Core Services (Mac :100.67.171.79)

  • Inference Proxy :11435 — 4-tier failover: T1 Windows GPU → T2 Pi → T3 Mac CPU → T4 Kimi Cloud
  • Dashboard :8080 — This UI (auth: sapphire)
  • Signal Logger :18081 — TradingView webhook ingest → Telegram
  • Control Plane :8082 — PM hub: projects, tasks, events
  • OpenBB API :6900 — 32 financial data providers
  • Regional Intel :8787 — Vote monitor + intelligence console
  • Hermes Bot — NousResearch Telegram agent (hermes3:8b)

Philosophy

  • PnL is king — Sortino/Calmar over Sharpe, 80%+ win rate target
  • Mac is commander; system must work without Pi cluster
  • Autonomous operation: 19 Claude scheduled tasks run 24/7
  • All Karpathy coding discipline principles applied to every task
02 Architecture ›

Sapphire uses a 4-tier inference mesh with the Mac as commander and Windows GPU as primary inference engine.

Inference Tiers

  • T1 Windows GPU (100.71.10.48) — RTX 5070 Ti, 27 Ollama models, ~0.4s latency
  • T2a rari1 (100.120.191.1) — Pi, nemotron-mini + smollm2 + qwen2.5:0.5b
  • T2b rari2 (100.87.225.89) — Pi, 4 models (offline — needs power cycle)
  • T3 Mac Local (127.0.0.1:11434) — 6 Ollama models, ~90s CPU fallback
  • T4 Kimi Cloud (api.moonshot.cn) — Non-sensitive tasks only, regex sensitivity gate

Model Aliases

  • fast / quick → nemotron-mini:4b (232 tok/s)
  • balanced → hermes3:8b (118 tok/s)
  • code → gemma4:latest (154 tok/s)
  • reason → deepseek-r1:14b (80 tok/s)
  • deep → qwen3:14b (81 tok/s)
  • large → qwen2.5:32b (2.7 tok/s)

Tailscale Mesh

  • Mac: 100.67.171.79 — Windows: 100.71.10.48 — rari1: 100.120.191.1 — rari2: 100.87.225.89
03 Security Protocols ›

Sapphire implements defense-in-depth with multiple security layers across all tiers.

Access Control

  • Basic Auth for dashboard (env: AUTH_PASSWORD)
  • Read-only public web interface — no mutations via UI
  • Sensitivity gate: regex blocks api_key/password/jwt/SSN/CC from T4 Kimi
  • Scoped control tokens + signed ingress headers

Operational Safety

  • Kill switch for emergency halt (macOS operator app only)
  • Paper-trade mode default — live trading requires explicit gate
  • ATR-based SL/TP: 1.67:1 R:R, 10% max position size
  • 60s health cooldown + 30s background probe on inference proxy
04 Trading Operations ›

Trading follows a multi-stage pipeline from signal to execution with 58% overall accuracy (BTC 75%).

Pipeline

  1. Signal Generation — TradingView Pine alerts → Windows webhook :9090
  2. Ingest — Signal logger (Mac :18081) normalizes + validates
  3. Scoring — 6-factor TA: RSI/MACD/BB/MA/ATR/volume
  4. Prediction — Kronos ML: 6-factor weighted scoring
  5. Notification — Hermes bot → Telegram alert
  6. Paper Trade — $100K paper portfolio, ATR stops, Sortino tracking

Metrics

  • Prediction accuracy: 58% overall, BTC 75%
  • R:R ratio: 1.67:1 (ATR-based)
  • Position sizing: 10% max
  • Target: Sortino/Calmar over Sharpe, 80%+ win rate

06 Troubleshooting ›

Service Issues

  • Dashboard won't start — Requires AUTH_PASSWORD env var
  • Inference proxy offline — Check com.sapphire.inference-proxy LaunchAgent
  • GPU Ollama empty responses — Proxy uses native /api/chat not /v1/; check Windows reboot (Scheduled Task)
  • Predictions chart missing — Chart.js served from /static/js/chart.min.js

Pi Cluster

  • rari1 SSH refused — Needs physical access to start sshd. Setup script: infra/pi/rpc-server-setup.sh
  • rari2 offline — Needs power cycle. rari2 ProtonVPN (proton0) breaks internet if tunnel dies

LaunchAgent Quick Restart

  • Dashboard: launchctl kickstart -k gui/$(id -u)/com.sapphire.dashboard
  • Inference proxy: launchctl kickstart -k gui/$(id -u)/com.sapphire.inference-proxy
  • Signal logger: launchctl kickstart -k gui/$(id -u)/com.sapphire.signal-logger

Mac Python

  • Use /usr/local/bin/python3 for tests — brew 3.14 may be missing pytest
  • Tests: pytest tests/unit/ --tb=short -q (1,088 tests)
