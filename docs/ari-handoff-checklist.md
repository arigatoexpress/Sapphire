# Ari's integrations handoff checklist — 2026-04-18

Everything below is gated on you personally — account creation, ToS acceptance, domain DNS, payment, or 2FA. Each section has the URL, the exact clicks, my recommended settings (with rationale), what to drop into `.env.integrations`, and the one-line verify command.

After each section:

```bash
# re-load and re-probe just the thing you just set up
scripts/load_integrations_env.sh
scripts/smoke_integrations.py <probe_name>
```

Total time if you do all eight in one sitting: **~75 minutes**, plus DNS-propagation waits on Resend.

## Loading creds + going live — the final flip

Once `.env.integrations` has the values you want to test:

```bash
# 1. tight perms (script refuses to load anything looser)
chmod 600 .env.integrations

# 2. shove them into launchd so the LaunchAgents can see them
scripts/load_integrations_env.sh

# 3. confirm everything is green
scripts/smoke_integrations.py
# expected: everything you've filled in → PASS, rest → SKIP, 0 FAIL

# 4. do a local dry-run of the publisher (still safe — SAPPHIRE_PUBLISH_LIVE unset)
/usr/local/bin/python3 -m lib.content --publish

# 5. if the dry-run Telegram ping looks right, flip to live
launchctl setenv SAPPHIRE_PUBLISH_LIVE 1
launchctl kickstart -k gui/$(id -u)/com.sapphire.content-publisher

# next scheduled run: Sunday 06:15 CT, 15 min after content-engine renders the report
```

## Rollback, if anything goes sideways

```bash
# 1. stop the publisher
launchctl setenv SAPPHIRE_PUBLISH_LIVE 0
launchctl kickstart -k gui/$(id -u)/com.sapphire.content-publisher

# 2. wipe all .env.integrations keys from the launchd GUI session
scripts/load_integrations_env.sh --unset

# 3. unload the LaunchAgent entirely
launchctl bootout gui/$(id -u) \
  ~/Library/LaunchAgents/com.sapphire.content-publisher.plist
```

Every key that lives in `.env.integrations` stays on disk at `chmod 600` — nothing gets shipped to GitHub. Rotation path: generate new key → replace in file → `scripts/load_integrations_env.sh` → `launchctl kickstart`.
