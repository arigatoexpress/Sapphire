# Factory Repo Fixer Runbook

Run by the cloud routine **Sapphire factory repo fixer** (cron `0 5 * * *`,
05:00 UTC = 23:00 America/Denver, one hour after `factory-test-guardian`).
Also the manual fallback if the routine is paused.

## Goal

Run the repo's mechanical formatters and linters in fix mode (`ruff
check --fix`, `ruff format`). If they produce any change, open a single
PR titled `chore: factory repo fixer auto-fixes (YYYY-MM-DD)` containing
exactly that diff — no other edits. If the tree is already clean, exit 0
silently.

## Critical Safety

- **Only `ruff` auto-fixes.** No type changes, no test edits, no
  semantic edits, no dependency bumps, no plist or `.env` touches.
- **One PR per run, draft.** Always open as draft. Never auto-merge.
- **Never push to `main` directly.** Always a feature branch.
- **Never modify** any path matching: `*secrets*`, `*.env*`,
  `*credentials*`, `data/`, `infra/launchagents/*.plist`,
  `services/*/launchagent/*.plist`, `~/Library/LaunchAgents/*` (which
  the cloud env should not have anyway).
- **Idempotent.** If a draft PR with title prefix
  `chore: factory repo fixer auto-fixes` is already open against `main`
  with no merge conflicts, update it (force-push the branch) instead of
  opening a second one.
- **No emojis** in titles, branches, commits, or PR bodies.
- **No `--no-verify`.** If pre-commit hooks fail on the auto-fix commit,
  fix the underlying issue or abandon the PR for that run.

## Steps

1. `gh auth status` must succeed. Otherwise exit 0 with no commit and
   log "no gh auth, skipping".

2. Confirm clean working tree on `main`:
   ```bash
   git checkout main
   git pull --ff-only origin main
   git status --short
   ```
   If working tree is dirty, exit 0 with no PR (cloud env should be
   clean; dirty indicates environment bug).

3. Install test deps so ruff is the same version as CI:
   ```bash
   pip install -r requirements-test.txt 2>&1 | tail -5
   ```

4. Compute today's date stamp `YYYY-MM-DD` (UTC). Use this for the
   branch name suffix and PR title.

5. Run ruff in fix mode:
   ```bash
   ruff check . --fix --exit-zero 2>&1 | tee /tmp/factory-ruff-check.log
   ruff format . 2>&1 | tee /tmp/factory-ruff-format.log
   ```
   `--exit-zero` so we don't fail on remaining unfixable issues — we
   only care whether anything changed.

6. Check for changes:
   ```bash
   git status --short
   ```
   If empty: exit 0 silently. Print `factory-repo-fixer: clean`.

7. Confirm the diff touches **only** non-restricted paths. Run:
   ```bash
   git diff --name-only | tee /tmp/factory-changed-files.txt
   ```
   For each line, refuse if it matches any of the paths in the
   "Critical Safety" restricted list. If any restricted path is touched,
   abandon the run: `git checkout .`, exit 0, and open a new issue
   labeled `factory-repo-fixer-blocked` with the file list (so a human
   investigates the unexpected mass change).

8. Search for an existing open draft PR:
   ```bash
   gh pr list --state open --search "chore: factory repo fixer auto-fixes" \
     --json number,title,headRefName,isDraft --limit 5
   ```
   If one exists and is `isDraft: true` and has no merge conflict,
   re-use that branch name. Otherwise create a new branch
   `factory/repo-fixer-<YYYY-MM-DD>`.

9. Commit and push:
   ```bash
   git checkout -B factory/repo-fixer-<YYYY-MM-DD>
   git add -A
   git -c commit.gpgsign=false commit -m "chore: factory repo fixer auto-fixes <YYYY-MM-DD>

   Mechanical ruff --fix and ruff format only. No semantic edits.
   Generated by the Sapphire factory-repo-fixer cloud routine."
   git push -u origin factory/repo-fixer-<YYYY-MM-DD> --force-with-lease
   ```

10. Open or update the draft PR:
    - Title: `chore: factory repo fixer auto-fixes <YYYY-MM-DD>`
    - Labels: `factory-repo-fixer`, `chore`.
    - Draft: yes.
    - Body sections:
      1. `## Summary` — file-count changed, line-count.
      2. `## Tools` — exact ruff version, command lines.
      3. `## Restricted-path check` — pass/fail (must be pass; fail
         abandons before this step).
      4. `## Reviewer guidance` — short paragraph: this PR is mechanical
         ruff output only; review by skimming the diff for any oddity
         and merging if clean. If conflict appears later, re-trigger the
         routine.

11. Print a one-line status summary to stdout: either
    `factory-repo-fixer: clean` or
    `factory-repo-fixer: <N> files changed, draft PR #<num>`.

## Required tools

`Bash`, `Read`, `Write`, `Edit`, `Glob`, `Grep`, plus `gh` on PATH.
The cloud routine config should include all six.

## Out of scope

- Fixing test failures. That's the human's call after factory-test-guardian
  opens an issue.
- Type-error fixes. ruff's auto-fixes are stylistic only by repo policy
  (see `pyproject.toml`); semantic fixes need human review.
- Dependency upgrades. Dependabot covers that lane.
