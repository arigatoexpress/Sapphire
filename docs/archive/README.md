# Sapphire Documentation Archive

This archive keeps historical audits and time-bound reports discoverable without
leaving stale conclusions in the active docs root.

Active documentation stays in `docs/` when it is current, product-facing, or
part of an operational runbook. Historical audits move under
`docs/archive/<year>/<topic>/` once a newer verification pass or runbook
supersedes them.
