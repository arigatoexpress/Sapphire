# TradingView Integration: Smart Money Breakout (AlgoAlpha)

This runbook wires your TradingView script to Sapphire gateway with:

- explicit `BUY`/`SELL` actions
- explicit symbol + quantity
- explicit TP/SL values from your script
- webhook secret in body (`passphrase`)

Gateway endpoint:

- `https://sapphire-gateway-267358751314.us-central1.run.app/webhook/tradingview`

## 1) TradingView Alert Mode

In TradingView, create one alert with:

- Condition: `Any alert() function call`
- Webhook URL: gateway endpoint above
- Message: **empty** (payload is generated by `alert()` in Pine)

## 2) Pine Alert Payload (drop-in logic)

Add these inputs near the top of your script:

```pine
webhookSecret = input.string("REPLACE_WITH_SECRET", "Sapphire Webhook Secret", group="Sapphire")
tradeQty      = input.float(0.01, "Sapphire Quantity", minval=0.0001, step=0.0001, group="Sapphire")
tpProfile     = input.string("TP1", "Sapphire TP Source", options=["TP1","TP2","TP3"], group="Sapphire")
```

Then replace/add alert calls inside `if highBroken` and `if lowBroken`:

```pine
tpLong = tpProfile == "TP1" ? TP : tpProfile == "TP2" ? TP1 : TP2
tpShort = tpProfile == "TP1" ? TP : tpProfile == "TP2" ? TP1 : TP2

if highBroken
    payloadLong = str.format(
      '{{"passphrase":"{0}","symbol":"{1}","action":"buy","price":{2},"quantity":{3},"take_profit":{4},"stop_loss":{5},"confidence":0.85,"time":"{6}"}}',
      webhookSecret,
      syminfo.ticker,
      str.tostring(close),
      str.tostring(tradeQty),
      str.tostring(tpLong),
      str.tostring(SL),
      str.tostring(time)
    )
    alert(payloadLong, alert.freq_once_per_bar_close)

if lowBroken
    payloadShort = str.format(
      '{{"passphrase":"{0}","symbol":"{1}","action":"sell","price":{2},"quantity":{3},"take_profit":{4},"stop_loss":{5},"confidence":0.85,"time":"{6}"}}',
      webhookSecret,
      syminfo.ticker,
      str.tostring(close),
      str.tostring(tradeQty),
      str.tostring(tpShort),
      str.tostring(SL),
      str.tostring(time)
    )
    alert(payloadShort, alert.freq_once_per_bar_close)
```

## 3) Current Lighter Guards (already active)

- Default TP/SL applied even when payload omits them:
  - TP: `3.0%`
  - SL: `2.0%`
- Single-symbol mode enabled:
  - one active symbol at a time on `bot-lighter`
  - new symbol is rejected while another symbol is active

## 4) Validation Checklist

1. Send one test BUY from TradingView.
2. Confirm in trades feed:
   - `success=true`
   - `metadata.stop_loss` and `metadata.take_profit` set
3. Send BUY on a different symbol while first symbol is active:
   - expect rejection: `Single-symbol mode active...`
4. Send SELL/exit signal on the same symbol:
   - should close (reduce-only behavior for EXIT/TP/SL signal types).
