# Kimi Trading Assistant Operations Contract

## Purpose
This document defines the live data contract your local Kimi/OpenClaw assistant should use for autonomous trading operations on Lighter.

## Primary Data Sources
- `equity_snapshots_current/lighter`
  - Latest equity, cash, unrealized PnL, drawdown/progress, sync freshness.
- `execution_verifications`
  - Per-signal execution audit trail (signal id, strategy, timeframe, fill qty, avg price, error).
- `assistant_ops_briefs/latest`
  - Consolidated operations brief generated by bot-lighter every few minutes.
- `positions/lighter_*` (or live status endpoint)
  - Current open positions, TP/SL, side, quantity, mark, unrealized PnL.

## Required Kimi Behaviors
1. Monitor every 2-5 minutes:
   - Equity progress vs baseline/peak.
   - Position count and exposure.
   - Last execution success/failure and fill quality.
2. Alert immediately on:
   - Drawdown threshold breach.
   - Stale data freshness warnings.
   - Execution failures or repeated retries.
3. Recommend action in plain English:
   - Hold / reduce risk / rotate opportunity / stop trading.
4. Never reveal secrets in chat output.

## Bot-Lighter Runtime Features (now enabled)
- Dynamic TP/SL repricing from market drift + volatility.
- EV scoring per signal and position (`ev_score_pct`).
- Single-symbol opportunity rotation when incoming EV edge is higher than configurable threshold.
- Assistant brief publishing to Firestore (`assistant_ops_briefs`).

## Environment Flags
- `LIGHTER_DYNAMIC_RISK_ENABLED=true`
- `LIGHTER_DYNAMIC_RISK_UPDATE_SECONDS=60`
- `LIGHTER_DYNAMIC_TP_TREND_BOOST_PCT=25`
- `LIGHTER_DYNAMIC_SL_TIGHTEN_PCT=20`
- `LIGHTER_DYNAMIC_VOL_WIDEN_PCT=20`
- `LIGHTER_OPPORTUNITY_ROTATION_ENABLED=true`
- `LIGHTER_OPPORTUNITY_MIN_EDGE_PCT=0.20`
- `LIGHTER_OPPORTUNITY_COOLDOWN_SECONDS=180`
- `LIGHTER_ASSISTANT_BRIEF_ENABLED=true`
- `LIGHTER_ASSISTANT_BRIEF_INTERVAL_SECONDS=300`

## Recommended Kimi Prompt Snippet
"You are my autonomous trading operations assistant. Read `assistant_ops_briefs/latest`, `equity_snapshots_current/lighter`, and recent `execution_verifications`. Every cycle, summarize: portfolio state, active risks, EV ranking, and a concrete recommendation (hold/rotate/reduce/stop). Escalate immediately on drawdown, stale data, or execution anomalies."
