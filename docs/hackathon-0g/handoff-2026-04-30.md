## Why the code is ready to ship even though I can't sign-as-you

- **All 0G code is gated by `SAPPHIRE_OG_ENABLED=1` + `OG_PRIVATE_KEY`.** With either unset (the default), Sapphire's trading critical path runs byte-identical to its pre-hackathon behavior. No latent regression risk.
- **Fire-and-forget hook on the signal_logger** never blocks or raises into the webhook. A failed 0G publish lands as a `data/system_events.jsonl` event for ops visibility but never delays a trade.
- **Pre-compiled ABIs in `data/chain/`** mean reviewers + CI can exercise `og_verify` without installing solc. Deploy still requires solcx, but day-of-judging doesn't.
- **Mainnet deploy is two-step** (`--check` then live deploy), identical to the existing Robinhood Chain pattern.
